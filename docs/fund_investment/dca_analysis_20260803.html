FIRST PRINCIPLES

跌幅不是价值，价格只是一个变量

长期回报 = 盈利与自由现金流增长 + 利息或可持续分红 +/- 估值变化 - 费用、永久损失与错误集中
  1. 设备跌近10%：只提高了相对昨天的安全边际；若绝对估值和资本强度仍高，跌后仍可昂贵。
  2. 医疗跌约1%：没有改变老龄化、创新药、器械国产化和支付约束，也不足以触发4%买入。
  3. 光伏新能源上涨：改变的是价格，不是产能、库存、毛利率和经营现金流。
  4. 消费下跌：估值赔率提高，但居民收入、渠道库存与现金回款仍要验证。
  5. AI需求与股东回报：收入必须覆盖GPU、网络、存储、电力、折旧和后续资本开支。
  6. 成本是沉没成本：是否卖出取决于从今天起的预期回报，不取决于能否回本。
6月制造业PMI为50.3%、新订单为51.2%；上半年规上工业利润增长18.7%，电子设备制造利润增长96.9%，但电气机械下降8.6%、汽车下降19.5%。这支持“产业利润重新分配”，不支持“所有行业盈利一起恶化”。

最新净值相对成本仍需上涨约18.7%回本，但成本不决定动作。医疗约27.47倍PE，长期受益于老龄化、创新药和器械国产化。上半年创新药对外授权81笔、总额约1100亿美元，并批准38个1类创新药和42个创新器械；但授权含或有里程碑，不能当作当期利润，也不能外推整个医疗行业。

资产层继续持有，不卖、不补；等待盈利预期稳定或新的合格买点。

消费、食品与白酒

上半年社零增长1.3%，居民人均可支配收入实际增长4.2%，消费支出实际增长2.7%，说明消费仍增长但强度偏弱。000083、001631与012414估值低至合理偏低，均持有观察；等待收入预期、渠道库存与现金回款至少两项改善。白酒C类份额过窄且长期费用需单独核对。

EXECUTION METHOD

跌超4%也不等于有效触发

质量门 → 估值门 → 基本面门 → 组合预算 → 记录实际买入确认净值 P → 下一笔仅在确认净值 <= 0.96P 时执行
  • 医疗、消费和白酒跌约1%，未达到价格条件。
  • 光伏与新能源上涨，不触发下跌分批。
  • 半导体设备和半导体跌超4%，但估值、周期现金流和基金质量门未通过，触发无效。
  • 红利低波只跌0.08%，且估值门未通过。
  • 债券基金、黄金与个股不适合机械套用同一规则。
当前还缺最后一次实际买入确认净值、金额和剩余预算。 4%法只能管理合格标的的执行节奏，不能把半导体设备跌9.70%变成自动买点。

ADVERSARIAL REVIEW

对抗式审查

半导体设备跌近10%，还不够便宜吗？

跌幅是相对昨天的变化，不是绝对价值。高估值、低利润基数和高资本开支行业跌后仍可能昂贵，现金流和估值门未通过前4%触发无效。

AI趋势确定，为什么不立刻建仓？

产业增长不等于股东回报。资本开支、折旧、竞争和买入估值都可能吞噬增长；你已有2.61%的科技观察仓，等待赔率不等于错过AI。

医疗合理偏低，为什么不补？

估值支持持有，但今日跌幅不足，主动基金持仓透明度有限，整体盈利拐点未确认。低估是必要条件，不是满仓的充分条件。

光伏逆势上涨，是否已经反转？

单日强势可能只是轮动。真正反转需要价格企稳、产能退出、库存下降和经营现金流共同确认。

红利低波只有8倍PE，为何不买？

必须与自身历史和股息率比较；约4.67%的股息率尚未提供明显安全边际，分红可持续性也需验证。

阿里上涨7%，是否已经确认价值？

单日上涨不会等比例增加未来自由现金流，反而直接减少新买入的安全边际。

为何资产层都持有，组合层又要调整？

“资产是否值得持有”和“应该持有多少”是两道题。好资产也可能与其他主题重复或占用过多风险预算。
