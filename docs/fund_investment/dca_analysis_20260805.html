FIRST PRINCIPLES

价格上涨没有自动创造现金流

长期回报 = 盈利与自由现金流增长 + 可持续分红或利息 +/- 估值变化 - 费用、资本开支、竞争和永久性损失
  1. 芯片上涨需要后续订单、毛利率、应收账款和自由现金流验证。
  2. AI资本开支增长不等于每个硬件、平台和应用公司都获得同等股东回报。
  3. 消费低PE只有在未来盈利没有永久下移时才是真便宜。
  4. 光伏和新能源终端需求增长，可能先惠及用户而非制造商股东。
  5. 主动基金一天上涨不代表持续超额，必须看适当基准和费后结果。

AI INDUSTRY

长期机会成立，今天不新增AI仓

AI股东回报 = AI收入 × 可持续利润率 - GPU、网络、存储、电力、折旧与融资成本 - 后续资本开支 - 买入估值

微软Azure增长43%说明需求真实；Meta收入增长28%，但高资本开支和较低自由现金流说明产业增长不等于股东现金同步增长。国内电子利润高增，也不能外推所有公司。

EXECUTION METHOD

今天没有有效4%触发

质量门 → 指标门 → 估值门 → 基本面门 → 组合门 → 记录最后一次实际买入确认净值 P → 下一笔仅在确认净值 <= 0.96P 时执行
  • 科技、医疗、光伏、新能源上涨，不触发向下4%。
  • 消费、酒和红利低波今日仅跌约0.7%-1.0%，三日跌幅也不能代替真实买点。
  • 红利低波当前没有持仓，不存在“上一次买点”。
  • 平均成本不是最后一次实际买入确认净值。
  • 个股、黄金和偏债基金不能机械套用行业基金规则。
结论：4%法负责合格资产的执行价格，不负责把下跌自动转化为价值。

ADVERSARIAL REVIEW

对抗式审查

半导体设备涨9.53%，为什么不买？

三日已转涨，半导体机械PE约108倍；价格上涨快于已确认现金流，安全边际不足。

007484今天可能大涨，二季度跑输还重要吗？

重要。一天高弹性描述风格，季度超额衡量工具结果；今天上涨不取消长期产品复核。

医疗合理偏低，为什么不补？

你持有的是前十大占75.1%的主动基金，不是医疗指数；行业估值不能覆盖选股集中风险。

红利低波三日跌3.24%，不是接近4%了吗？

当前没有该持仓或真实首次买点，长期分位也未确认；4%法不能创造首次买入许可。

为什么不等亏损基金回本再卖？

成本是历史信息。若工具质量持续失败，更合格资产的机会成本不会等你回本。

天弘永利占近一半，为什么不直接卖？

它虽含权益且阶段性跑输，仍有大量固定收益资产。应先明确资金用途、赎回成本和替代工具，再分批调整。
