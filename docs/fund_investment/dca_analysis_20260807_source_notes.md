## 7. 医疗上涨原因的证据边界

已确认事实：CXO、创新药、生物科技和医疗ETF同时上涨，且`003095`主要持仓普遍上涨。

可以提出、但不能写成已确认因果的解释：

1. 部分CXO和创新药企业盈利、订单及商业化预期改善，市场重新定价未来现金流。
2. 医药板块经历较长时间估值压缩，风险偏好回升时具备更高修复弹性。
3. 创新药审批、医保支持和对外授权改善长期预期，但里程碑金额不等于当期自由现金流。
4. 资金从前一日强势的煤炭、银行轮动至高弹性成长行业。

未确认事项：没有找到一项8月7日当日的一手公告，能够单独解释整个医疗板块上涨。因此不能宣布行业已经进入全面盈利拐点。
