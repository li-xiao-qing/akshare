FIRST PRINCIPLES

上涨首先改变价格和折现率

长期回报 = 盈利与自由现金流增长 + 利息或可持续分红 +/- 估值变化 - 费用、永久损失与错误集中
  1. 高实际利率：仍约束远期现金流久期较长的高估值科技；官方日表不能证明利率下降是今天的确定催化。
  2. 反弹没有创造现金流：通信和AI涨幅必须由后续订单、利润率与资本回报验证。
  3. 两日优于单日：半导体设备仍跌4.47%，今天主要是修复。
  4. 消费下跌：提高价格赔率，但没有改善居民信心、库存和批价。
  5. 红利低波下跌：提高股息率，仍需利润与现金流覆盖。
  6. 主动基金不是指数：003095昨日跌2.84%，明显偏离医疗指数。
  7. 成本是沉没成本：未来预期回报决定卖出，不由能否回本决定。

HOLDING ACTIONS

按基金与行业本身判断

防守产品

天弘永利债券B（420102）和汇添富鑫享添利（012951）继续持有。权益大涨不是卖出防守资产的充分理由；新增要检查久期、信用风险、权益仓位和资金期限。

中欧医疗健康A（003095）

最新净值相对成本仍需上涨约22.1%回本。行业约28倍PE合理偏低，长期受益于老龄化、创新药和器械国产化；但基金昨日跌2.84%，明显弱于医疗指数，主动持仓偏离是首要风险。继续持有，不因反弹卖出；新增前先核验最新季报和业绩归因。

消费、食品和白酒

000083、001631和012414估值偏低，但社零、库存、批价和现金回款尚未反转。现有份额持有、不割肉、不补仓；白酒C类过窄且长期费用需要单独处理。

光伏与新能源

终端装机、电动车和储能需求长期增长，制造商回报却受过剩产能、降价和持续资本开支制约。011102与012831继续持有、不追连续上涨；等待价格企稳、产能退出、库存下降和经营现金流中至少两项改善。

海外与科技

摩根标普500A（017641）可作为海外核心雏形；华安纳指100A（040046）和广发纳指100A（270042）高度重复，现有份额持有。信澳核心科技A（007484）小仓持有、不追涨；先核验重仓、换手、费用和费后超额收益。

AI INDUSTRY

反弹不等于风险解除

AI股东回报 = AI收入 × 可持续利润率 - GPU、存储、网络、电力、折旧与融资成本 - 后续资本开支 - 买入时支付的估值

昨夜风险偏好改善和昨日急跌后的均值回归，可以解释今天成长反弹。两日结构更重要：通信涨9.45%、云计算涨4.31%、AI涨3.23%，但半导体和设备仍跌2.32%和4.47%。市场更愿意重估网络、光通信和平台应用，同时继续给高资本开支硬件更高风险折价。

长期回报 = 可持续股息率 + 盈利增长 +/- 估值变化 - 分红下调、行业集中、税费与产品费用
  1. 当前PE仍高于7月22日约7.62倍，当时历史分位已约67.7%，所以大概率仍非低估区。

EXECUTION METHOD

今天没有有效4%触发

质量门 → 估值门 → 基本面门 → 组合预算 → 记录实际买入确认净值 P → 下一笔仅在确认净值 <= 0.96P 时执行
  • 医疗、科技、光伏、新能源上涨，不能追买。
  • 消费和白酒跌约1.6%，未达到4%，基本面门也未完全通过。
  • 红利低波跌2.16%，未达到4%，估值仍非明确低估。
  • 债券、黄金和个股不适合机械套用同一规则。
  • 当前缺少最后一次实际买入确认净值、金额与剩余预算。
4%法只管理合格标的的执行价格。 它不预测底部，也不会把下跌自动变成价值增加。

    主动基金完整持仓、行业暴露、换手率和费后超额收益尚未穿透；接口读取持仓失败。

  4. 04
    缺少最后一次实际买入确认净值、金额与战术预算，4%法无法严谨落地。
  5. 05
    持仓文件仍是20260723快照，后续交易或分红会使估算偏离。

最大遗漏是主动基金透明度，不是少看一个热门行业。 行业估值只能回答行业赔率，不能替代基金真实持仓与费后结果。

ADVERSARIAL REVIEW

对抗式审查

科技大涨是否证明昨天只是错杀？

不能。半导体设备和半导体两日仍分别跌4.47%和2.32%，只有订单、利润率和自由现金流改善才能证明价格低于价值。

通信涨9.45%，为什么不追最强方向？

涨幅提高价格，却没有同步增加同等幅度的现金流。客户集中、扩产、应收账款、毛利率和估值都需要核验。

医疗合理偏低，为什么不补？

行业估值支持持有，但主动基金已显著偏离指数；今天价格上涨后，新增资金的证据不足。

消费和白酒低估且继续跌，为何不买？

只通过估值门，需求、库存和回款尚未确认，跌幅也未达到4%执行条件。

红利低波的回调不是期待的买点吗？

它正在接近买点，但当前PE和股息率仍未进入明确历史低估，首笔预算和场外产品也未复核。

光伏新能源连续上涨，是否完成出清？

价格上涨只说明预期变化；出清需要价格企稳、产能退出、库存下降和自由现金流共同验证。

资产层都持有，为何组合层还要调整？

资产质量与适合持有多少是两道题。好行业也可能与其他持仓重复或占用过多风险预算。
