FIRST PRINCIPLES

3. 第一性原理：上涨究竟改变了什么

长期资产回报
= 盈利与自由现金流增长
+ 可持续分红或利息
+/- 估值变化
- 费用、资本开支、竞争和永久性损失

基金没有脱离底层资产的独立价值。基金长期回报等于成分公司的股东回报减去费用、交易损耗、经理错误和跟踪误差。

8月7日确认的是：市场愿意用更高价格购买医疗、芯片和成长制造的未来现金流。它没有自动确认：

  1. 医疗企业订单、研发成功率和自由现金流已经全面进入新周期。
  2. 半导体约113倍机械PE可以由未来利润完全消化。
  3. 光伏、新能源已经完成产能、库存、价格和资产减值出清。
  4. 消费的低PE会立即转化为收入增长。
  5. 红利低波下跌一天就进入严格低估区。

因此，正确动作不是追逐今天最强行业，也不是机械卖出当天上涨最多的持仓，而是检查现金流、竞争结构、估值和工具质量是否发生足以改变长期回报的新变化。今天没有足够证据改变资产层动作。

HOLDING QUALITY

6. 按基金和行业本身判断

6.1 医疗与003095

医疗ETF上涨4.53%，多只创新药ETF上涨约6.5%。按二季报权重，003095前十大对净值的加权贡献约+5.36个百分点；凯莱英、药明康德、康龙化成、泰格医药等CXO与创新药公司联动上涨。

可以确认的是行业发生广泛重估，不能确认的是全面盈利拐点。合理解释包括订单与盈利预期改善、创新药政策和对外授权预期、长期估值压缩后的弹性，以及资金从前一日防守板块轮动到成长板块。

医疗机械PE由约28倍升至29.2倍，仍未进入必须卖出的高估区。003095前十大约占75.1%，又决定了它不能无条件追加。

结论：行业和产品均继续持有；不因一天大涨机械减仓，也不在大涨日追买。 后续新增需要盈利预测稳定、估值提供更大安全边际，并具备真实4%锚点。

6.2 消费、食品饮料与白酒

消费和白酒约19倍PE、4%以上股息率，估值已经具有长期研究价值。但上半年社零只增长1.3%，6月增长1.0%，低估值仍缺少收入、库存和现金回款的持续确认。

000083前十大盘中加权贡献约-0.52个百分点，美的、海尔、海大和福耀回落，因此基金可能弱于上涨0.45%的消费ETF。

结论：行业持有等待基本面；000083、001631、012414停止重复新增，长期只保留一个消费工具。

6.3 光伏与新能源

光伏和新能源分别上涨2.49%和2.20%。终端装机、电动车和储能需求仍有长期空间，但制造商股东回报取决于产能退出、产品价格、存货和固定资产减值、应收回款及自由现金流。

结论：资产继续持有、不追涨、不补仓。 以后卖出或替换应依据产业现金流和工具质量，不能把“回到成本价”当作唯一条件。

6.4 核心科技007484

其二季报前十大更偏中小盘芯片、封装、软件和IT硬件，而不是单一AI指数。今日前十大加权贡献约+1.36个百分点，估算基金上涨1.5%至3.0%。

但该基金二季度上涨4.76%，同期基准上涨29.07%，落后约24.31个百分点。今天上涨衡量风格弹性，季度超额衡量产品质量，两者不能互相替代。

结论：现有小仓持有，停止新增；若连续季度费后超额仍不修复，分批替换为透明度更高、费用更低的工具。

6.5 偏债基金与QDII

国债ETF上涨0.05%、短融ETF上涨0.01%。420102二季末约含12.8%股票，012951约含6.1%股票；两者继续持有，但都不能直接等同于现金。

AI INDUSTRY

7. AI产业：长期机会与今天的动作

AI股东回报
= AI增量收入 × 可持续利润率
- GPU、网络、存储、电力、折旧与融资成本
- 后续资本开支
- 买入估值

微软FY2026 Q4收入增长18%、Azure增长43%、商业剩余履约义务增长84%，说明企业云和AI需求真实。Meta Q2收入增长28%，但单季资本开支310.8亿美元、自由现金流仅7.84亿美元，说明AI扩张也可能先消耗股东现金。

8月7日半导体、半导体设备和通信上涨，云计算接近平盘，软件下跌。它支持“算力硬件仍有景气交易”，不支持“所有AI公司的收入和利润同步加速”。

你的账户已经通过007484、两只纳指、标普500以及偏债产品中的科技股获得AI参与权。当前直接科技仓位不高，但“仓位不高”不是在高估值时强行补足的理由。

长期优先级：

  1. 云平台与应用：必须看到付费收入、续费率、毛利率和自由现金流。
  2. 网络、光通信、存储、电力与冷却：必须看到订单质量、应收回款、客户集中和扩产回报。
  3. 国产设备、材料与先进封装：必须验证客户、良率、折旧和中周期利润。
  4. 只有AI标签、没有收入和现金流的公司，不进入长期核心。

今日动作：不新增AI主题基金，不追涨半导体；继续用现有小仓观察商业化。

8.1 红利低波

红利低波长期回报
= 可持续股息率 + 盈利增长 +/- 估值变化
- 分红削减、行业集中、费用和税费

红利低波ETF（512890）下跌0.69%，机械PE约7.67倍、股息率约4.93%。绝对收益率具有吸引力，但缺少可靠完整十年分位，不能严格宣布已经进入历史20%低估区。

低PE还可能反映银行、能源等行业增长较慢和盈利周期风险。真正买入前还需检查股息是否由自由现金流覆盖、指数换仓规则，以及场外联接基金是否实际现金分红。

结论：今天继续观察，不因为下跌0.69%立即建立首仓。 如果家庭确实缺少战略分红资产，可另行制定1%-2%试仓方案，但那属于资产配置，不是今日估值或4%触发。

8.2 A股宽基

沪深300机械PE约14.87倍，属于合理偏高。账户缺少明确A股宽基核心是长期结构问题，但不能为了补结构而追涨。

结论：未来优先用新资金，在沪深300或更广宽基进入合理偏低时建立核心；不卖出低位行业后立即追买今日上涨的宽基。

10. 4%定投法：今天是否触发

质量门 -> 指标门 -> 估值门 -> 基本面门 -> 组合门
-> 记录最后一次实际买入确认净值P
-> 下一笔仅在确认净值 <= 0.96P时执行
  • 今日多数风险资产上涨，不构成向下4%的价格触发。
  • 账户仍缺少每只基金最后一次实际买入确认净值、金额和剩余预算。
  • 平均持仓成本不等于最后一次实际买入净值。
  • 红利低波没有现有仓位，不存在可供4%法使用的上一次买点。
  • 个股、黄金、主动基金和偏债基金不能机械套用指数基金规则。

结论：8月7日没有任何可审计的4%买入触发。 估值法决定“值不值得买”，4%法只决定“合格后何时分批买”。

ADVERSARIAL REVIEW

13. 对抗式审查

医疗大涨，为什么不趁机减仓

减仓需要“价格超过合理价值”或“组合必须再平衡”的证据。医疗约29.2倍机械PE不属于明显高估，今天也没有基本面恶化。只因为上涨就卖出，会把波动误当价值变化。

医疗估值不高，为什么又不追买

合理偏低不等于极度低估；003095还是高集中主动基金。今天上涨已经减少安全边际，且缺少真实4%锚点，追买的赔率下降。

半导体涨得更强，为什么不增加AI仓

半导体机械PE超过113倍，价格已经要求未来利润高速兑现。软件下跌也说明AI商业化并未全面同步。产业机会真实，不代表任何价格都值得买。

红利低波只有7倍PE、近5%股息率，为什么不买

它长期增长较慢且行业集中，绝对PE天然低于成长指数。估值法要求与自身历史、股息覆盖和产品分红规则比较，而不是与AI横向比较数字。

光伏、新能源仍亏损，为什么不等回本再卖

成本价不影响未来现金流。若行业现金流和供给结构改善，低于成本也可能继续持有；若逻辑破坏，高于成本也应退出。等待回本属于锚定偏差，不是估值依据。

账户今天大涨，是否说明组合已经合理

不是。今日收益主要由单一医疗风险因子贡献，消费和纳指重复、科技工具质量、宽基缺失及交易数据问题都没有因此消失。
