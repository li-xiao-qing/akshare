## 3. 第一性原理：反弹是否改变长期判断

长期回报近似为：

```text
长期回报
= 底层企业盈利增长
+ 利息与可持续分红
+/- 估值变化
- 管理费、交易费和错误集中
```

今天价格上涨主要改变了估值项，没有同时证明所有行业盈利改善。

1. **市场宽度确实修复。** 4253只股票上涨，说明昨天的科技冲击没有演变为全市场流动性危机。
2. **科技相对弱势延续。** 科创50、半导体、设备、材料和云计算在大盘上涨时继续下跌，说明AI硬件拥挤度和资本回报率仍被重新定价。
3. **消费医疗上涨不等于基本面反转。** 低估资产在资金轮动时可以上涨，但持续行情最终必须由收入、利润率、自由现金流和可持续分红支撑。
4. **你的历史成本仍是沉没成本。** 是否持有应比较从今天开始的预期回报和替代资产，而不是等待价格回到买入成本。

## 10. 4%定投法

4%法不是“下跌4%就买”，而是：

```text
标的先通过质量、估值、基本面和组合门
→ 建立首笔并记录确认净值P
→ 下一笔只在确认净值不高于0.96P时执行
```

今天没有新的买入触发：

- 医疗估值合理，但仓位门失败。
- 消费估值偏低，但产品重复且连续上涨。
- 光伏、新能源基本面门失败。

## 13. 对抗式审查

### 质疑一：4253只股票上涨，是否应该开始乐观买入

市场宽度修复降低了系统性流动性风险，但没有自动降低所有资产估值。沪深300、红利低波和AI仍未通过各自估值门。

### 质疑二：医疗今天上涨，为什么反而建议减仓

医疗估值合理，但账户权重约22.7%。反弹提供降低集中风险的执行窗口，不代表行业没有价值。减到10%-12%后仍能参与行业长期修复。

### 质疑三：消费连续上涨，是否应该加仓

消费估值不高，但你已经有三只重叠产品。继续加仓会扩大产品重复和行业集中。正确动作是去重，而不是根据两天涨幅增加产品数量。

### 质疑四：AI跌了很多，为什么还不能抄底

今天大盘和4253只股票上涨，而AI、云计算、半导体和设备继续下跌，说明其相对弱势尚未结束；近似PE仍约56倍和146倍。产业趋势正确不能替代买入价格和资本回报率。

### 质疑五：防守仓占56%，是否错过上涨

会有机会成本，但当前核心资产尚未全部出现足够安全边际。先卖防守再追逐反弹，会把结构调整变成新的择时错误。防守仓应在核心买点出现时逐步释放。
