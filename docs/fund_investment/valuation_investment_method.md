# 估值投资法与4%定投法统一执行手册

整理日期：20260715

本文是估值投资法、4%定投法、基本面检查和组合风险控制的唯一执行文档。核心目标不是预测短期涨跌，而是用统一规则决定“什么可以买、何时分批买、买多少、何时停止和何时卖出”。

> 风险提示：本文是方法研究和执行模板，不构成投资建议。估值、分批买入和分散投资都不能保证盈利，也不能避免本金损失。历史分位、回测、基金分红和过往业绩均不代表未来收益。

## 1. 两个基本概念与核心结论

### 1.1 两个基本概念

**估值投资法**：通过PE、PB、PS、股息率等指标，结合企业基本面和历史分位，判断资产当前处于低估、合理还是高估区域，从而决定允许买入、继续持有或分批卖出。它主要回答“现在能不能买”。

**4%定投法**：当标的已经通过基本面、估值和仓位检查后，以最近一次实际买入确认净值为基准，每下跌4%执行一份预先规划的资金；上涨时不追买。它主要回答“允许买以后，下一份什么时候买”。

两者需要与仓位控制共同使用：估值投资法决定买卖方向和许可，4%定投法决定执行节奏，仓位控制决定即使便宜还能买多少。任何一种方法都不能单独预测短期涨跌或保证盈利。

### 1.2 “4%定投法”并非严格意义上的传统DCA

传统DCA通常是按固定时间间隔投入相同金额，不考虑市场涨跌。本文沿用“4%定投法”这一名称，但它实际是：

~~~text
估值过滤后的下跌触发分批买入法
~~~

两者的差别是：

| 方法 | 触发条件 | 优点 | 主要代价 |
| --- | --- | --- | --- |
| 传统DCA | 固定时间、固定金额 | 简单，持续参与市场 | 高估时仍会买入 |
| 4%定投法 | 相比上次实际买点下跌4% | 避免上涨时追价，保留后续资金 | 单边上涨时可能长期踏空，震荡或暴跌时可能快速耗尽预算 |

4%法更适合管理已经准备好的战术资金池，不应替代应急现金、长期战略资产配置或正常的工资结余定投。应先确定长期战略目标权重，再把战术资金限定为其中一部分；除非明确接受长期低仓位，否则不能把全部计划权益资金都留给4%触发。

### 1.3 两种方法的分工

~~~text
基本面和第一性原理：决定标的是否值得长期持有
估值投资法：决定当前是否允许买、停止买或开始卖
组合风险控制：决定即使便宜，是否还有仓位可以买
4%定投法：以上条件通过后，决定下一份何时执行
~~~

估值与4%跌幅不是两个独立预测信号。盈利不变时，价格下跌4%，PE也大致下降4%。二者结合的主要价值是执行纪律和资金管理，而不是叠加两个模型后保证提高胜率。

## 2. 第一性原理

### 2.1 权益资产为什么有价值

股票和股票基金的长期价值最终来自底层企业未来能够分配给股东的现金流：

~~~text
内在价值 = Σ（未来自由现金流 × 实现概率）÷（1 + 要求回报率）^时间
~~~

权益资产的长期总回报可以近似拆解为：

~~~text
总回报 ≈ 盈利增长 + 现金分红 + 估值变化 - 费用 - 税费
~~~

因此：

1. 价格下跌不自动增加价值，只有长期现金流没有同步恶化时，安全边际才可能提高。
2. 低PE可能来自盈利处于周期高点，不能直接等同于便宜。
3. 高股息可能来自股价暴跌或不可持续分红，基金分红本身也不会凭空创造收益。
4. 估值只能改善多年期预期回报的赔率，对短期涨跌的预测能力很弱。

### 2.2 真正需要控制的风险

短期波动不是唯一风险。需要优先控制的是：

- 标的现金流或竞争优势发生永久性恶化。
- 单一行业、国家、币种或风险因子过度集中。
- 备用资金在下跌早期耗尽，后续被迫停止或卖出。
- 使用了不适合该资产的估值指标。
- 因赎回费、税费、基金限购或流动性导致规则无法执行。
- 短期必用资金进入高波动资产，被迫在不利价格退出。

方法必须先控制永久损失和组合生存，再讨论提高收益。

## 3. 完整决策顺序

每一笔买入必须依次通过以下六道门：

~~~text
质量门：长期需求、现金流和竞争逻辑仍然成立
    ↓
指标门：使用的估值指标适合该资产
    ↓
估值门：处于低估或合理偏低，而不是只看绝对倍数
    ↓
基本面门：低估不是盈利高点、财务恶化或结构性衰退造成
    ↓
组合门：买入后不突破单一标的、行业和相关风险因子上限
    ↓
价格门：首仓足够小，或达到上次实际买点的96%
~~~

任何上游条件失败，4%的价格触发都无效。

## 4. 估值指标的选择

估值不是价值本身，而是价格相对某个基本面锚的比率。

| 资产类型 | 优先指标 | 辅助指标 | 主要陷阱 |
| --- | --- | --- | --- |
| 盈利稳定的宽基、消费 | PE、盈利收益率 | PB、PS、股债利差 | 盈利增速永久下降 |
| 银行、保险、证券 | PB、ROE | PE、股息率、资产质量 | 杠杆和金融周期使低PE失真 |
| 煤炭、能源、化工等周期行业 | PB、周期中枢现金流 | 产能、股息率 | 盈利高点时PE最低 |
| 科技、半导体、未稳定盈利行业 | PS、PB、自由现金流 | 毛利率、研发效率、资本开支 | 远期增长无法兑现 |
| 医疗和创新药 | PE/PB/PS组合 | 管线成功率、支付政策、现金流 | 研发失败、政策变化和高久期 |
| 红利指数 | 股息率、自由现金流覆盖 | PE、PB、分红稳定性 | 不可持续分红或行业过度集中 |
| 黄金 | 实际利率、美元、央行及避险需求 | 历史价格和组合保险需求 | 没有盈利，不能使用PE/PB |
| QDII权益基金 | 底层指数或持仓估值 | 汇率、税费、跟踪误差 | 净值下跌可能来自汇率而非底层资产变便宜 |
| 主动基金 | 穿透后的行业和持仓估值 | 基金经理、换手和风格稳定性 | 持仓披露滞后且可能风格漂移 |
| 债券基金 | 到期收益率、久期、信用风险 | 利率周期、回撤 | 不适合用权益PE或机械4%补仓 |

当PE、PB、PS或股息率明显冲突时，应先解释冲突。不能简单多数投票，也不能只挑最支持买入的指标。

## 5. 历史估值分位的用法

| 历史分位 | 状态 | 基础动作 | 附加条件 |
| --- | --- | --- | --- |
| 0%-20% | 低估 | 允许建立首仓并进入4%买入流程 | 必须通过基本面和仓位检查 |
| 20%-50% | 合理偏低 | 已有仓持有；缺少仓位时可用更小首仓 | 要求更高质量或更长持有期 |
| 50%-80% | 合理偏高 | 持有为主，通常停止新增 | 等待盈利消化估值 |
| 80%-100% | 高估 | 增长无法解释估值时分批减仓 | 不猜顶，不一次性清仓 |

这些阈值是执行语言，不是自然规律。使用前还要确认：

1. 历史窗口至少覆盖一轮以上完整周期。
2. 当前利率、监管、会计和产业结构没有使历史中枢永久改变。
3. 指数调仓没有造成估值序列突然跳变。
4. 数据使用同一口径，例如加权PE不能和等权PE直接比较。
5. 分位数据日期与交易决策日期匹配，不能把滞后数据当成实时数据。

## 6. 适用标的

| 适用程度 | 标的 | 用法 |
| --- | --- | --- |
| 较高 | 规则透明、长期有效的宽基指数基金 | 最适合标准估值和4%流程 |
| 中等 | 消费、医疗等长期需求较稳定的行业指数 | 需要更低仓位上限和行业基本面复核 |
| 较低 | 新能源、光伏、半导体、证券等周期行业 | PE容易失真，应结合PB、现金流和周期位置 |
| 较低 | 主动权益基金 | 必须穿透持仓，定期检查基金经理和风格漂移 |
| 不宜机械使用 | 个股 | 每次下跌都要重新检查财报、现金流和投资论点 |
| 不适用 | 货币基金、普通债券基金 | 收益来源和波动结构不同 |
| 不适用股票估值法 | 黄金 | 只按宏观保险需求和组合上限管理 |

指数成立时间较短、成分变化大或历史数据质量差时，估值分位可靠性应下调，而不是强行套用十年阈值。

## 7. 先确定风险预算

### 7.1 资金分层

开始前先把资金分成三层：

| 资金层 | 用途 | 是否使用4%法 |
| --- | --- | --- |
| 应急和短期支出 | 日常、应急及未来1-3年明确支出 | 不使用 |
| 长期战略配置 | 按目标比例长期持有和定期再平衡 | 通常不依赖4%触发 |
| 战术分批资金 | 等待低估标的并分批投入 | 可以使用 |

4%法只能使用第三层资金。不能因为出现买点而挪用应急现金或借款。

至少每季度复核战术现金占比和长期目标权重。等待时间本身不会产生买入信号；若长期战略仓位不足，应按独立的资产配置和再平衡规则处理，不能临时把4%法改成追涨。

### 7.2 从可承受损失反推仓位

单一风险因子的理论上限应从压力损失反推：

~~~text
最大权重 <= 可接受该风险因子造成的组合损失 ÷ 压力情景下该风险因子的跌幅
~~~

例如，只愿让某行业在压力情景中拖累组合不超过5%，并假设该行业可能下跌40%，则理论权重上限为：

~~~text
5% ÷ 40% = 12.5%
~~~

这只是压力测试示例，不是通用仓位建议。实际还应降低以下重复暴露：

- 多只基金持有同一行业或同一批重仓股。
- 医疗、养老产业等名称不同但成分重叠。
- 新能源、光伏、电池等共享同一产业周期。
- 纳指基金、主动科技基金和科技个股共享成长因子。
- 港股、QDII和个股共同暴露于同一国家或币种。

仓位必须按底层风险因子合并计算，不能只按基金代码分散。

## 8. 首次买入与4%买点

### 8.1 首次买入

没有真实成交记录时，不存在正式的“上一买点”。首次买入必须同时满足：

1. 六道门全部通过。
2. 已确定该标的总预算和压力情景。
3. 已确定买入份数，且下跌超出压力情景时不会临时追加预算。
4. 已检查申购费、销售服务费、赎回费、持有期、限购和到账时间。
5. 首笔成交后记录实际确认净值，不使用盘中估算作为锚点。

### 8.2 后续买入公式

~~~text
下一买点 = 上一次实际买入确认净值 × 0.96
~~~

第n次买入对应的理论价格为：

~~~text
第n次买点 = 首次实际买入净值 × 0.96^(n-1)
~~~

| 买入次数 | 相对首次买点 | 相对首次买点跌幅 |
| ---: | ---: | ---: |
| 1 | 1.0000 | 0.00% |
| 2 | 0.9600 | -4.00% |
| 3 | 0.9216 | -7.84% |
| 4 | 0.8847 | -11.53% |
| 5 | 0.8493 | -15.07% |
| 10 | 0.6925 | -30.75% |
| 18 | 0.4996 | -50.04% |

这说明“分成10份、每跌4%买一份”只能覆盖首次买入后约31%的连续下跌。若压力情景是下跌50%，理论上需要约18次买入，而不是10次。

所需份数可近似计算为：

~~~text
份数 >= 1 + ceil[ ln(1 - 压力跌幅) ÷ ln(0.96) ]
~~~

该公式假设每次金额相同、成交恰好位于理论触发价，并且净值口径前后一致。实际跳空和开放式基金最终确认净值会改变覆盖深度，所以它只能用于预算压力测试，不能预测实际成交路径。

压力情景不是预测最低点，而是检验预算能否在不利路径下生存。若所需份数过多、单份金额过小或交易成本过高，应缩小总仓、放弃该标的或改用长期战略配置，不能临时扭曲规则。

### 8.3 有效锚点

只能使用：

- 上一次实际买入的最终确认净值。
- 已扣除分红除息、份额拆分等机械变化影响的可比价格。

不能使用：

- 持仓平均成本。
- 上一日净值。
- 盘中估算净值。
- 观察日净值。
- 曾经想买但没有成交的价格。

锚点生命周期还应遵守：

1. 价格上涨不会把锚点向上重置，下一买点仍基于最后一次实际买入净值。
2. 因高估、论点变化或组合再平衡发生卖出后，被卖部分的旧买点序列终止；以后重新进入时按新的首仓处理。
3. 锚点不会替代基本面复核。每次触发前都要重过六道门；即使没有触发，也至少每季度复核一次，并在季报、指数调仓、重大政策或基金经理变化后重新审查。
4. QDII净值触发时，要拆分底层资产涨跌和汇率影响。只有底层资产估值与组合仓位仍通过，才允许执行。

### 8.4 跳空、除息和同时触发

1. 一天跨过多个4%档位时，不追溯补齐多份。先复核基本面，单次最多执行一份，再以真实成交净值设新锚点。
2. 基金分红会导致净值机械下降。若总资产没有发生同等损失，不能把除息跌幅当作4%买入信号。
3. 多个高度相关基金同时触发时，按合并风险预算排序，不能每只各买一份。
4. 暂停申购、限购、折溢价异常或流动性不足时，触发价不等于可执行价格。
5. 每次交易金额应足以覆盖费用影响，不能为了精确4%而进行低效小额交易。

## 9. 停止买入和卖出规则

### 9.1 立即停止买入

出现任一条件即停止：

- 投资论点或底层现金流逻辑失效。
- 估值回到50%分位以上。
- 买入后会突破标的、行业或相关风险因子上限。
- 战术预算已经用完。
- 数据失真、持仓不透明或基金发生明显风格漂移。
- 交易费用、限购或流动性使执行成本不可接受。

### 9.2 卖出优先级

| 优先级 | 原因 | 动作 |
| ---: | --- | --- |
| 1 | 投资论点永久失效 | 重新评估退出，不能因低估继续摊薄 |
| 2 | 仓位突破风险上限 | 减回目标仓位，即使标的仍低估 |
| 3 | 估值进入80%以上且增长无法解释 | 分3-5次减仓 |
| 4 | 组合再平衡 | 上涨后偏离目标权重时恢复配置 |
| 5 | 资金用途变化 | 在可控时间内降低风险，不临时赌价格 |

低估标的也可能因组合过度集中而减仓。此时卖出是风险控制，不是预测它即将下跌。

## 11. 执行示例

### 11.1 低估宽基

假设某宽基通过六道门，首次确认净值为1.0000，战术预算为10,000元，压力情景为首次买入后下跌约30%。按4%间距需要约10份，每份约1,000元：

| 次数 | 触发净值 | 买入金额 | 动作 |
| ---: | ---: | ---: | --- |
| 1 | 1.0000 | 1,000元 | 建立首仓并记录锚点 |
| 2 | 0.9600 | 1,000元 | 六道门仍通过后执行 |
| 3 | 0.9216 | 1,000元 | 重新检查估值和仓位 |
| 4 | 0.8847 | 1,000元 | 继续按真实成交价更新锚点 |
| 10 | 约0.6925 | 1,000元 | 预算最后一份，之后不追加 |

如果价格持续上涨，没有下一买点就不补买。其代价是可能只持有一小部分仓位，这是4%法主动接受的机会成本。

### 11.2 医疗低估但仓位过高

医疗估值处于低位，只能说明标的层面允许持有。若医疗已占风险资产一半以上，组合门失败：

- 不执行4%加仓。
- 保留长期核心仓。
- 可以按风险上限小幅再平衡。

估值低与组合减仓并不矛盾，两者回答的是不同问题。

### 11.3 基金分红造成净值下降

若基金净值因分红从1.0000降至0.9600，同时每份派发0.0400现金，持有人总价值没有因市场下跌4%。这不是有效买点，必须调整锚点或使用复权总回报口径。

## 12. 常见误区

| 误区 | 正确处理 |
| --- | --- |
| 只要跌4%就买 | 必须先通过质量、指标、估值、基本面和组合检查 |
| 把4%法当作传统DCA | 它是价格触发策略，会有长期持币和踏空风险 |
| 以上一日净值或平均成本为锚 | 只能用上一次实际确认净值 |
| 一天跌12%就补三份 | 先复核新信息，单次最多一份 |
| 基金分红后净值跌4%就买 | 除息不是经济损失，应调整锚点 |
| 多只相似基金分别设置上限 | 应按底层风险因子合并计算 |
| 低PE就是低估 | 周期盈利高点可能制造虚假低PE |
| 行业基金无限补仓 | 先设置压力情景、总预算和退出条件 |
| 估值高就一次性清仓 | 先检查增长，再分批减仓和再平衡 |
| 等最低点和最高点 | 方法只追求可执行区间，不预测极值 |

## 13. 对抗式审查

以下从“怎样让这套方法失败”出发检查其薄弱点：

| 攻击场景 | 失败机制 | 当前防线 | 剩余风险 |
| --- | --- | --- | --- |
| 价值陷阱 | 盈利永久下降，估值越跌越低 | 基本面门和论点失效条件 | 仍可能误判结构性衰退 |
| 周期高点低PE | 利润见顶使PE虚假便宜 | 周期行业优先看PB、现金流和产能 | 周期拐点无法精确识别 |
| 历史中枢失效 | 利率、监管或产业结构改变 | 检查历史窗口和制度变化 | 新范式只能事后确认 |
| 单边牛市 | 首仓后不再下跌4%，大量现金踏空 | 明确4%法仅用于战术资金 | 收益可能长期落后一次性投入 |
| 路径依赖 | 相同终点价格因途中波动不同产生不同成交次数 | 固定锚点生命周期并记录真实成交 | 方法结果仍依赖价格路径而非只依赖终值 |
| 快速暴跌 | 4%档位密集触发并耗尽预算 | 压力情景份数公式、单次最多一份 | 暴跌超过压力情景仍会亏损 |
| 多资产同时下跌 | 表面分散的资产相关性升至接近1 | 合并风险因子和组合预算 | 极端市场下历史相关性失真 |
| 除息或数据错误 | 机械净值下降制造假信号 | 使用复权口径并核对数据日 | 数据源仍可能延迟或修订 |
| 主动基金风格漂移 | 参考指数与真实持仓脱节 | 穿透持仓并定期复核 | 定期报告天然滞后 |
| QDII汇率错觉 | 汇率造成净值下跌，但底层资产没有变便宜 | 拆分资产回报和汇率贡献 | 汇率本身仍难预测 |
| 旧锚误用 | 卖出或新周期后继续沿用历史买点 | 卖出终止对应买入序列 | 部分卖出时仍需人工准确记录 |
| 高估后继续高涨 | 过早卖出优质成长资产 | 检查增长能否解释估值并分批卖 | 仍可能明显跑输趋势行情 |
| 高频小额交易 | 费用和税费侵蚀收益 | 交易前检查总费用和最低有效金额 | 不同平台费率会变化 |
| 行为失控 | 下跌时停买，上涨时追买 | 预先记录预算、锚点和失效条件 | 执行仍依赖投资者纪律 |
| 现金挪用 | 备用资金被消费或临时加码其他标的 | 三层资金隔离 | 个人现金流变化无法由策略控制 |

审查结论：

1. 方法没有消除市场风险，只把决策过程变得可记录和可约束。
2. 4%不是经过证明的最优间距，只是行为和资金管理参数；有效性必须结合标的波动、费用和压力情景验证。
3. 这套方法最薄弱的环节不是公式，而是基本面误判、相关性低估和执行者临时改变预算。
4. 对已有一笔大额现金，分批投入通常降低短期路径风险，但可能付出持币机会成本；不能宣称必然优于一次性投入。
5. 对持续工资结余，传统定期DCA可能比等待4%下跌更简单；两类资金不应混用同一规则。
6. 在没有包含费用、分红再投资、样本外数据和基准策略的回测前，只能把本方法视为风险控制框架，不能宣称具有稳定超额收益。

## 14. 数据与验证要求

正式执行前必须记录：

| 项目 | 内容 |
| --- | --- |
| 估值 | 数据日、指标定义、加权方式、历史窗口和分位 |
| 基本面 | 盈利趋势、现金流、ROE、分红覆盖或行业周期 |
| 仓位 | 当前权重、买后权重、相关风险因子合并权重 |
| 风险预算 | 压力跌幅、允许组合损失、总预算和份数 |
| 买点 | 实际确认净值、金额、下一96%触发价和复权调整 |
| 费用 | 申购费、销售服务费、赎回费、税费和持有期 |
| 退出 | 高估条件、论点失效条件和目标权重 |

评价方法是否有效，应使用包含分红再投资和费用的总回报，并至少比较：

- 持续定期投入同一宽基。
- 一次性投入。
- 固定资产配置加定期再平衡。
- 不使用估值过滤的4%分批策略。

同时检查最大回撤、资金利用率、最长持币时间、交易次数和样本外表现，不能只展示成功案例。回测还必须避免使用事后才知道的数据、当前成分股倒推历史、幸存者偏差和反复调参；20%/50%/80%分位与4%间距都应在未参与参数选择的样本外区间复核。

## 15. 方法边界

这套方法能够：

- 降低在高估区集中买入的概率。
- 降低一次性抄底和早期耗尽资金的风险。
- 把情绪决策转化为可记录、可复核的流程。
- 在标的、估值和仓位同时通过时提供明确执行点。

这套方法不能：

- 保证盈利、回本或跑赢市场。
- 识别最低点和最高点。
- 防止行业永久衰退、公司造假或政策冲击。
- 替代资产配置、分散投资和现金管理。
- 证明4%优于3%、5%或传统定期投入。

成功标准不是每次买入后立即上涨，而是在完整周期内，以可承受的永久损失风险和回撤完成既定资产配置，同时避免情绪破坏计划。
