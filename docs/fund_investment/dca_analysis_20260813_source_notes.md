- **工具层**：三只QDII产品重叠；光伏与新能源共享产业风险；白酒、食品饮料、主动消费重叠；医疗主动基金前十集中度高；`007484`并非纯AI指数。
- **组合层**：医疗约23.9%且单基金前十约75.1%；偏债约54.7%但不是等价现金；家庭房产、保险、负债、现金和实物黄金未知。
- **执行层**：仓库没有每只基金最后一次实际买入确认净值、买入金额和剩余预算，因此 **不得声称触发4%买点**。估值法先决定能否买，4%法只决定合格资产如何分批买。

## 10. 对抗式审查：寻找结论错误的证据

1. 医疗今日强势可能只是高波动反弹；二季报持仓滞后且研发、支付政策风险未消失，不能由单日上涨推出基本面反转。
2. 光伏下跌不自动提高价值；若价格竞争、过剩产能和资本回报继续恶化，低价可能对应更低未来现金流。
3. AI产业收入增长真实，但证券价格已反映很高增长；天孚、寒武纪等行情PE很高，任何订单/收入低于预期都可能导致估值压缩。
4. 红利低波估值低并非无风险；分红不可持续、银行/能源集中和利率变化都可能破坏防御属性。
5. 两只偏债占比高看似降低波动，但转债今日 -0.87%，证明“偏债=现金”的假设错误；仍需穿透久期、信用和股票仓位。
6. QDII上一交易日上涨不等于今日基金净值同幅上涨，汇率、跟踪误差、时区和申赎费用都会造成偏差。
7. 阿里约20倍行情PE看似不贵，但必须用云资本开支后的自由现金流和核心商业竞争检验；中芯高利用率同时伴随高折旧/资本开支，不能机械使用PE。

当前最大的遗漏：真实交易流水与4%锚点、家庭资产负债表、基金当日最终净值、8月13日正式指数估值/长期分位、主动基金7月以来调仓。这些遗漏均应降低动作置信度。
