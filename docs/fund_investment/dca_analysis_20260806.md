## 3. 第一性原理：今天到底改变了什么

```text
长期资产回报
= 盈利与自由现金流增长
+ 可持续分红或利息
+/- 估值变化
- 费用、资本开支、竞争和永久性损失
```

8月6日确认的是边际资金偏好和价格变化，没有自动确认：

1. 半导体设备订单、毛利率和自由现金流足以支持约109倍机械PE。
2. 煤炭价格与盈利可以覆盖周期顶部回落和资本开支风险。
3. 医疗下跌代表创新药、CXO和器械的长期盈利预测恶化。
4. 光伏、新能源已经完成库存、落后产能和减值出清。
5. 消费的低PE能够抵消需求增速下降。

因此，今日正确动作不是追最强行业或卖最弱行业，而是检查原投资论点是否出现新的现金流证据。结论是：**没有足够的新证据改变现有资产动作。**

## 10. 4%定投法：今天是否触发

```text
质量门 -> 指标门 -> 估值门 -> 基本面门 -> 组合门
-> 记录最后一次实际买入确认净值P
-> 下一笔仅在确认净值 <= 0.96P时执行
```

- 今日所有持仓净值涨跌均未达到向下4%。
- 账户仍缺少每只基金最后一次实际买入确认净值、金额和剩余预算。
- 平均持仓成本不等于最后一次买入锚点。
- 红利低波没有现有持仓，不存在可供4%法使用的上一次买点。
- 个股、黄金和偏债基金不能机械套用行业指数基金规则。

**结论：8月6日没有任何有效4%买入触发。**

## 11. 当前最大的遗漏

1. **持仓快照停留在7月23日。** 后续申赎、分红和转换会令账户重估失真。
2. **007484成本字段存在算术不一致。** `fund_holdings.md`中的成本2.4468、净值1.2788与收益率-21.58%不能同时成立，必须以平台交易流水和累计分红核对。
3. **基金名称隐藏真实风险。** `420102`和`012951`都含权益；AI暴露也分散在多个基金中。
4. **二季报持仓有滞后。** 当前穿透只代表6月30日，主动基金可能已经调仓。
5. **长期估值分位不完整。** 不能严谨宣布红利低波进入20%低估区。
6. **4%执行记录缺失。** 没有最后买入净值和预算就无法复现纪律。
7. **家庭层资产未知。** 现金、房产、保险、负债和黄金敞口会改变组合风险上限。

**今天最大的遗漏不是一个新行业，而是缺少可审计的交易与成本数据。** 如果输入数据不能闭环，回本距离、4%触发和组合收益都会被错误数字污染。

## 13. 对抗式审查

### 医疗今天下跌，估值又不高，为什么不补

行业赔率尚可，但“合理偏低”不是“极度低估”；`003095`还是高集中主动基金。缺少真实4%锚点和新的盈利上调证据，今天下跌只提供观察，不提供执行许可。

### 煤炭上涨5.88%，为什么不追最强行业

追买需要假设煤价、产量与分红可以持续覆盖周期回落风险。今天只确认价格上涨，未确认长期自由现金流同步增加；更高价格反而降低安全边际。

### 007484上涨，是否说明基金经理已经修复

不能。单日上涨0.78%说明当前持仓有硬件弹性；二季度落后基准24.31个百分点衡量的是更长周期的工具结果。至少需要连续季度费后超额验证。

### 红利低波只有7倍PE、近5%股息率，为什么还不买

它长期增长较慢且行业集中，绝对PE天然低于成长指数。估值法要求与自身历史和股息可持续性比较，而不是与AI或消费横向比数字。

### 阿里和中芯都下跌，为什么不是买点

一天跌幅只改变价格2%-4%。阿里从合理估值略微变便宜，但未到深度低估；中芯在下跌后PE仍超过100倍，安全边际没有由一天回撤创造出来。

### 医疗、光伏、新能源亏损，为什么仍持有

今天没有新的永久性损失证据，单日卖出只是把价格波动当基本面。继续持有不等于永远持有；未来退出依据是现金流、供给结构和工具质量，不是等待回本。
