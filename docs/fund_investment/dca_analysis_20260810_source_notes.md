## 9. 涨跌原因的证据边界

已确认事实：全A超过4000家上涨，消费、医药、资源、地产和军工共同上涨；AI、通信、云计算和机器人下跌；半导体设备与半导体整体方向相反。

可以提出、但不能写成已确认因果的解释：

1. 前期拥挤且估值较高的AI风险因子出现获利回吐，资金扩散到低估值和滞涨行业。
2. 医疗和消费具备估值修复条件，但一天上涨没有确认盈利全面反转。
3. 资源、地产和军工上涨扩大了市场广度，说明并非单一医药或消费行情。
4. 半导体设备相对强势可能反映国产替代和订单预期，但广义半导体、通信与AI回落说明产业链没有同步改善。

未确认事项：截至报告制作时，没有找到一项8月10日当日的一手公告能够单独解释全市场风格切换。因此报告只确认价格结构，不杜撰统一催化剂。
