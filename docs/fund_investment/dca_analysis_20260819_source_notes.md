## 11. 对抗式审查与未确认风险

1. **“跌幅大就自动变便宜”可能错误。** 盘中价格下降会机械降低同口径估值，但盈利、自由现金流、资本开支和风险溢价可能同时变化；8月19日正式PE/PB/分位尚未取得。反过来，若盈利未变，今天的价格下跌确实改善未来赔率，因此完全拒绝后续加仓也可能错过估值修复；正确动作是先补锚点与正式估值，而不是永久禁买。
2. **“银行和红利上涨就是避险胜出”可能过度解释。** 价格相对抗跌是事实，但金融/周期集中、分红覆盖和利率敏感性没有被日内价格验证。
3. **“AI产业逻辑失效”没有证据。** AI、芯片、通信和半导体设备ETF跌约7%—8%，只说明证券价格与风险偏好快速调整；产业订单、收入、回款和资本开支后自由现金流需用公司正式披露验证。
4. **“出现普跌就触发4%买入”不成立。** 基金盘中代理不能替代最终确认净值；仓库仍缺逐只最后一次真实买入确认净值，不能据此声称任何基金达到96%执行价。
5. **涨跌家数可能有样本差异。** 腾讯宽度合计5210家且不含北交所，未与交易所官方统计复核；主报告应保留“二级行情样本”标签。
6. **成交额字段定义未完全确认。** 上证指数与深证成指接口的 `amount` 简单合计用于同日可比快照，不能无条件等同最终两市股票成交额。
