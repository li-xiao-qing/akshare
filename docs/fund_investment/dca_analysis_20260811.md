## 3. 第一性原理：价格下跌改变了什么

```text
长期资产回报
= 盈利与自由现金流增长
+ 可持续分红或利息
+/- 估值变化
- 费用、资本开支、竞争和永久性损失
```

8月11日主要改变的是市场愿意支付的价格，不是所有企业的产能、订单和现金流。正确问题不是“今天跌了要不要卖”，而是：

1. 未来现金流是否永久减少？
2. 当前价格相对可持续利润是否足够便宜？
3. 你持有的基金能否可靠获得这份行业回报？
4. 即使判断错误，仓位和现金流能否承受？

今天没有证据证明医疗、消费、光伏或AI的长期现金流统一恶化；同样也没有证据证明光伏上涨、光模块反弹就是盈利拐点。资产层动作因此以持有和等待证据为主。

## 7. AI产业：今天的分化意味着什么

AI股东回报

2. 盈利增长很快但估值已经包含更高预期的公司。

## 8. 红利低波与A股宽基

### 8.1 红利低波

```text
红利低波长期回报
= 可持续股息率 + 盈利增长 +/- 估值变化
- 分红削减、行业集中、费用和税费
```

红利低波ETF上涨`0.09%`，机械PE约`7.74倍`、股息率约`4.92%`。从绝对值看，约12.9%的盈利收益率和约4.9%的股息率有吸引力；但此前核验的自身历史PE分位约在65%附近，说明它天生低PE，不能仅凭个位数PE宣布进入历史低估区。

两种互不混淆的执行方案：

- **严格估值法：继续等待自身历史分位回到50%以下，20%以下才定义低估。**
- **战略配置法：若家庭确实没有红利资产，可把总金融资产1%-2%作为首仓上限。** 这叫补齐配置，不叫低估或4%触发。

场外产品继续只选一个：低费率和灵活性优先观察`016129 景顺长城中证红利低波动100ETF发起联接C`；必须贴近`512890`时比较`007466/007467 华泰柏瑞中证红利低波ETF联接`。基金分红会除息，历史分红不保证未来。

### 8.2 A股宽基

沪深300机械PE约`14.76倍`，仍是合理偏高，不是低估。账户缺少A股宽基核心是结构问题，但今天0.81%的下跌没有创造足够安全边际。

结论：未来用新资金在宽基进入合理偏低时建立核心；不卖出低位行业后立即追买宽基。

## 10. 4%定投法：今天是否触发

```text
质量门 -> 指标门 -> 估值门 -> 基本面门 -> 组合门
-> 记录最后一次实际买入确认净值P
-> 下一笔仅在确认净值 <= 0.96P时执行
```

- 今日持仓相关方向没有单日下跌4%。
- `007484`估算跌幅不足1.3%，且产品质量门没有通过。
- 消费下跌约1%，估值偏低但基本面确认不足，且已有三只重复产品。
- 红利低波没有实际首笔成交，不存在正式4%锚点。
- 平均持仓成本不能替代最后一次实际买入净值。

**结论：8月11日没有任何可审计的4%买入触发。** 估值法决定“能不能买”，4%法决定“合格后如何分批买”，两者不能倒置。

6. **家庭层资产未知。** 现金、房产、保险、负债和实物黄金会改变风险预算。

**今天最大的遗漏不是新行业，而是缺少可审计交易账本。** 没有它，4%触发、累计收益和回本距离都可能被错误输入污染。

## 13. 对抗式审查

### 市场今天跌了，为什么不买低估消费和医疗

一天约1%的回调没有显著改变长期赔率。消费基本面确认不足，医疗已有23.95%暴露；价格门不能绕过基本面门和组合门。

### 医疗最近上涨后回落，为什么不先减仓锁定收益

锁定收益不是独立估值理由。医疗约29.7倍机械PE并未明显高估，今天也没有基本面恶化。组合集中要求停止新增，但不能推出资产必须卖出。

### 光伏逆势上涨，是否说明已经反转

不是。真正反转需要产能退出、价格企稳、库存和减值下降、自由现金流改善。一天相对强势最多说明资金预期变化。

### 光模块龙头反弹，为什么不买AI

新易盛、中际旭创上涨并未带动寒武纪和半导体设备；AI指数估值仍高。个别公司订单兑现不能证明所有AI基金当前都便宜。

### 红利低波PE只有7.74倍，为什么不直接买

低增长、高分红行业长期就应低PE；它相对自身历史并不低。可以为了战略分散建立极小首仓，但不能把它包装成严格低估买点。

### 今天全部持有，是否意味着以后永远不卖

不是。消费和纳指重复、`007484`产品质量、偏债底层风险都需要长期处理；只是今天没有足够证据要求立刻交易。
