# 4%定投法执行手册

整理日期：20260707

基于“雷牛牛4%定投法（强化版）”整理：先看估值，再看跌幅，用分批资金避免追涨杀跌。

> 风险提示：本文是方法总结和执行清单，不构成任何投资建议。基金过往业绩不代表未来表现，市场有风险，投资需谨慎。

## 1. 一句话定义

在定投目标处于**合理偏低或低估区间**时，相较于**上一个买入点**，每下跌 4% 买入一次，直到预设资金用完；上涨时不追，等待高估后分批卖出。

核心不是“跌了就买”，而是：

1. 先确认标的值得长期持有。
2. 再确认估值不贵。
3. 最后按每跌 4% 的价格纪律分批买入。

## 2. 核心公式

| 项目 | 规则 |
| --- | --- |
| 首次买入 | 必须先满足估值合理偏低或低估；不要因为短期下跌直接买。 |
| 下一买点 | `上一买入净值 x 0.96`。例：上一买点 `1.0000`，下一买点 `0.9600`。 |
| 连续买点 | 每次都以上一次实际买入净值为基准：`0.9600`、`0.9216`、`0.8847`…… |
| 买入金额 | 新手可把单一标的预算分成 10 份，触发一次买一份。 |
| 停止买入 | 估值回到中位数以上、标的不再符合条件、或预算已用完。 |
| 卖出原则 | 低估分批买入，高估分批卖出，中间波动尽量少操作。 |

## 3. 适用标的筛选

| 优先级 | 标的类型 | 执行建议 |
| --- | --- | --- |
| 高 | 宽基指数基金 | 最适合标准 4% 法。优先选择发布时间超过 7 年、盈利与估值关系稳定的指数。 |
| 中 | 消费、医药等长期需求较稳定的行业指数 | 可使用，但要看行业估值；行业集中风险高于宽基。 |
| 低 | 新能源、光伏、半导体、证券等周期行业 | 不能只看市盈率；更适合结合市净率、行业景气度和仓位上限。 |
| 低 | 主动权益基金 | 持仓不透明，不能直接看基金自身估值；可参考沪深 300、中证全指或对应行业指数估值。 |
| 不适用 | 债券基金、货币基金 | 净值波动小、收益来源不同，不适合机械按 4% 下跌补仓。 |

## 4. 执行流程

| 步骤 | 动作 | 判断标准 |
| --- | --- | --- |
| 1 | 确定标的 | 优先选宽基或长期逻辑清楚的指数基金；不要同时买很多高度重复的基金。 |
| 2 | 确认估值 | 低于 20% 百分位优先；最差也应低于 50% 百分位；高于 50% 通常只持有不买。 |
| 3 | 设置预算 | 单一标的预算建议不超过总资产的 40%；普通行业基金应更低。 |
| 4 | 拆分份额 | 新手可分 10 份；极端低估且确定性强时可分 5 份，但风险更高。 |
| 5 | 记录买点 | 每次买入后记录日期、净值、金额、下一触发价。 |
| 6 | 等待触发 | 净值跌破上一买点的 96% 才买；没跌到就不动，上涨也不追。 |
| 7 | 高估卖出 | 估值进入 80% 百分位以上，开始分批止盈，不等最高点。 |

## 5. 仓位纪律

| 规则 | 建议 |
| --- | --- |
| 单一标的上限 | 宽基也不建议满仓单吊；单一基金或单一指数不要超过总仓位 40%。 |
| 行业基金上限 | 白酒、医疗、新能源、光伏、半导体等行业基金波动大，建议明显低于宽基。 |
| 跨市场分散 | 可用 A 股宽基、港股宽基、美股宽基分散风险，而不是在同一主题买多只重复基金。 |
| 子弹用完 | 若全部预算用完仍下跌，不再临时加码；持有低估筹码，等待估值修复。 |
| 现金管理 | 4% 法依赖耐心和备用资金，不要用短期必用的钱执行。 |

## 7. 常见误区

| 误区 | 正确做法 |
| --- | --- |
| 只要跌 4% 就买 | 错误。必须先满足估值合理偏低或低估。 |
| 以上一日净值为基准 | 错误。应以上一次实际买入净值为基准。 |
| 上涨后补买 | 错误。4% 法的优势就是避免追涨；没买满也接受少赚。 |
| 主动基金照搬指数规则 | 不严谨。主动基金只能参考市场或行业整体估值。 |
| 行业基金无限补仓 | 风险很高。周期行业可能长期低迷，必须设置仓位上限。 |
| 等最高点卖出 | 不可控。高估后分批卖出，比猜顶更可执行。 |

## 8. 每次操作前检查清单

每次买入前，至少确认以下事项：

- [ ] 标的仍符合长期投资逻辑，不是因为热门才买。
- [ ] 估值处于合理偏低或低估区间。
- [ ] 当前净值已跌破上一买点的 96%。
- [ ] 本次买入后仍不超过单一标的仓位上限。
- [ ] 已记录本次买入净值和下一触发价。
- [ ] 这笔资金三年以上不用。

## 9. 简单示例

假设某指数基金已经处于低估区间，第一次买入净值为 `1.0000`，总预算为 `10,000` 元，分成 10 份，每份 `1,000` 元。

| 次数 | 触发净值 | 买入金额 | 说明 |
| --- | ---: | ---: | --- |
| 1 | 1.0000 | 1,000 | 估值低估后首次买入。 |
| 2 | 0.9600 | 1,000 | 相比上次买点下跌 4%。 |
| 3 | 0.9216 | 1,000 | 再以下跌后的买点为基准。 |
| 4 | 0.8847 | 1,000 | 继续按纪律执行。 |

如果价格上涨，没有触发下一买点，就不补买；如果估值进入高估区间，开始分批卖出。

## 10. 方法边界

4% 定投法是纪律化买卖框架，不保证盈利。它依赖四个前提：

1. 标的长期有效，而不是基本面持续恶化。
2. 估值判断合理，而不是只看净值跌幅。
3. 资金分配克制，不在单一行业或单一基金上无限补仓。
4. 能长期执行，不因短期亏损或上涨诱惑破坏规则。
