FIRST PRINCIPLES

3. 第一性原理：价格下跌改变了什么

长期资产回报
= 盈利与自由现金流增长
+ 可持续分红或利息
+/- 估值变化
- 费用、资本开支、竞争和永久性损失

8月11日主要改变的是市场愿意支付的价格，不是所有企业的产能、订单和现金流。正确问题不是“今天跌了要不要卖”，而是：

  1. 未来现金流是否永久减少？
  2. 当前价格相对可持续利润是否足够便宜？
  3. 你持有的基金能否可靠获得这份行业回报？
  4. 即使判断错误，仓位和现金流能否承受？

今天没有证据证明医疗、消费、光伏或AI的长期现金流统一恶化；同样也没有证据证明光伏上涨、光模块反弹就是盈利拐点。资产层动作因此以持有和等待证据为主。

6.1 医疗与003095

医疗ETF下跌0.57%，创新药上涨0.33%，说明行业内部并非统一走弱。003095前十大按二季报权重贡献约-0.11个百分点，估算基金约-0.6%至+0.1%。

医疗机械PE约29.7倍，不属于高估，也不是足以忽略研发失败、医保支付和集中持仓风险的极端低估。创新药出海、老龄化和器械国产化仍有长期需求，但现金流兑现需要逐家公司验证。

资产结论：继续持有，不因回吐减仓，也不因“医疗低估”补仓。 组合层面它占23.95%、基金前十大占75.10%，因此停止新增；这与医疗资产本身是否值得持有是两个独立问题。

6.2 消费、食品饮料与白酒

主要消费下跌1.30%、白酒下跌0.90%。000083前十大贡献约-0.30个百分点，茅台仅下跌0.17%，没有出现龙头基本面被市场一致否定的证据。

约19至20倍PE和4%以上股息率提供了安全垫，但低估只解决买入价格，不解决需求疲弱、渠道库存和现金回款。文章中的茅台直营价格与缺货是渠道线索，尚不足以证明整个白酒行业复苏；“茅台是茅台”反而意味着不能把茅台外推到所有酒企。

资产结论：持有，不因今天回调补仓。 000083、001631、012414停止重复新增，长期只留一个工具；是否合并依据工具质量和费用，不等待回本。

6.3 光伏与新能源

光伏上涨0.70%、新能源下跌0.04%，光伏出现相对强势，但一天上涨无法证明产业出清。制造业股东回报最终取决于：

终端需求增长
- 过剩产能与价格战
- 折旧、减值和资本开支
- 应收与库存占用
= 可分配自由现金流

结论：现有仓持有、不追光伏、不补新能源。 价格、库存、产能退出和自由现金流至少三项共同改善后，才重新评估新增。

AI INDUSTRY

7. AI产业：今天的分化意味着什么

AI股东回报
= AI增量收入 x 可持续利润率
- GPU、网络、存储、电力、折旧与融资成本
- 后续资本开支
- 买入估值

微软FY2026 Q4收入增长18%、Azure增长43%，Meta Q2收入增长28%，说明AI需求真实；但Meta单季资本开支310.8亿美元、自由现金流仅7.84亿美元，也说明产业增长可能先吞噬现金。

8月11日新易盛上涨3.93%、中际旭创上涨2.59%，天孚通信下跌0.24%，寒武纪下跌2.97%。这不是“AI重新牛市”或“AI产业崩坏”，而是市场在区分：

  1. 已经有订单、利润和现金流的基础设施公司。
  2. 盈利增长很快但估值已经包含更高预期的公司。
  3. 只有题材、尚未形成可持续自由现金流的公司。

AI主题机械PE约56倍、半导体约112倍、科创50官方口径约97倍。即使长期增长成立，当前价格仍要求多年高增长和高资本回报同时兑现。

你的动作：不新增AI主题或半导体基金，不追光模块反弹。 账户已通过007484和美股QDII参与AI；先观察云收入、订单质量、应收、毛利率、资本开支和自由现金流，而不是看“AI”标签。

长期优先关注：能形成现金流的云平台与应用、光通信和网络、电力与冷却、存储、国产设备材料与先进封装。关注不等于现在买入。

DIVIDEND & CORE

8. 红利低波与A股宽基

8.1 红利低波

红利低波长期回报
= 可持续股息率 + 盈利增长 +/- 估值变化
- 分红削减、行业集中、费用和税费

红利低波ETF上涨0.09%，机械PE约7.74倍、股息率约4.92%。从绝对值看，约12.9%的盈利收益率和约4.9%的股息率有吸引力；但此前核验的自身历史PE分位约在65%附近，说明它天生低PE，不能仅凭个位数PE宣布进入历史低估区。

两种互不混淆的执行方案：

  • 严格估值法：继续等待自身历史分位回到50%以下，20%以下才定义低估。
  • 战略配置法：若家庭确实没有红利资产，可把总金融资产1%-2%作为首仓上限。 这叫补齐配置，不叫低估或4%触发。

10. 4%定投法：今天是否触发

质量门 -> 指标门 -> 估值门 -> 基本面门 -> 组合门
-> 记录最后一次实际买入确认净值P
-> 下一笔仅在确认净值 <= 0.96P时执行
  • 今日持仓相关方向没有单日下跌4%。
  • 007484估算跌幅不足1.3%，且产品质量门没有通过。
  • 消费下跌约1%，估值偏低但基本面确认不足，且已有三只重复产品。
  • 红利低波没有实际首笔成交，不存在正式4%锚点。
  • 平均持仓成本不能替代最后一次实际买入净值。

结论：8月11日没有任何可审计的4%买入触发。 估值法决定“能不能买”，4%法决定“合格后如何分批买”，两者不能倒置。

ADVERSARIAL REVIEW

13. 对抗式审查

市场今天跌了，为什么不买低估消费和医疗

一天约1%的回调没有显著改变长期赔率。消费基本面确认不足，医疗已有23.95%暴露；价格门不能绕过基本面门和组合门。

医疗最近上涨后回落，为什么不先减仓锁定收益

锁定收益不是独立估值理由。医疗约29.7倍机械PE并未明显高估，今天也没有基本面恶化。组合集中要求停止新增，但不能推出资产必须卖出。

光伏逆势上涨，是否说明已经反转

不是。真正反转需要产能退出、价格企稳、库存和减值下降、自由现金流改善。一天相对强势最多说明资金预期变化。

光模块龙头反弹，为什么不买AI

新易盛、中际旭创上涨并未带动寒武纪和半导体设备；AI指数估值仍高。个别公司订单兑现不能证明所有AI基金当前都便宜。

红利低波PE只有7.74倍，为什么不直接买

低增长、高分红行业长期就应低PE；它相对自身历史并不低。可以为了战略分散建立极小首仓，但不能把它包装成严格低估买点。

今天全部持有，是否意味着以后永远不卖

不是。消费和纳指重复、007484产品质量、偏债底层风险都需要长期处理；只是今天没有足够证据要求立刻交易。
