## 3. 第一性原理：价格上涨改变了什么

```text
长期回报
= 底层盈利与自由现金流增长
+ 可持续分红或利息
+/- 估值变化
- 费用、资本开支、竞争和永久性损失
```

今天确认的是价格、成交活跃度和风险偏好上升，没有自动确认以下事项：

1. 半导体设备的订单、毛利率和自由现金流是否足以支持更高估值。
2. AI资本开支是否最终转化为平台、应用和硬件股东的可分配现金。
3. 光伏、新能源的供给过剩、库存和减值是否完成出清。
4. 消费低估是否来自暂时弱需求，还是长期增长中枢下降。
5. 红利低波股息是否可持续，基金是否真的现金分红。
6. 主动基金是否能持续跑赢适当基准，而不是只在某一天高弹性上涨。

因此，今天上涨提高了现有持仓净值预期，却降低了新增资金的安全边际。

## 10. 4%定投法：今天是否触发

```text
质量门 -> 指标门 -> 估值门 -> 基本面门 -> 组合门
-> 记录最后一次实际买入确认净值P
-> 下一笔仅在确认净值 <= 0.96P时执行
```

- 科技、医疗、光伏、新能源上涨，没有向下4%触发。
- 消费、酒和红利低波今日跌幅约0.7%-1.0%，三日约跌3.2%-3.4%，仍不能代替实际买入锚点。
- 红利低波当前没有持仓，首次买入应先通过估值与产品门，不存在“上次买点”。
- 个股、黄金和偏债产品不能机械套用行业基金的4%规则。
- 当前持仓文件只有平均成本，没有最后一次实际买入确认净值和剩余预算。

**结论：今天没有任何有效4%买入触发。**

## 11. 当前最大的遗漏

1. **基金名称隐藏真实风险。** `420102`含12.8%股票，`012951`也含科技股；防守仓不是纯债，AI暴露也不只在科技基金。
2. **007484产品质量需要连续验证。** 单季落后基准24.31个百分点，且大幅调仓；不能因今天上涨忽略。
3. **基金持仓有滞后。** 二季报截至6月30日，7月至今可能再次调仓。
4. **十年估值分位缺失。** 中证官方文件只有近期序列，不能严谨宣布红利低波进入20%低估区。
5. **4%法缺少实际锚点。** 平均成本不是上一次确认净值。
6. **持仓快照仍停留在7月23日。** 账户估算可能遗漏后续交易与分红。

**今天最大的认知修正：资产类别、基金名称和真实底层暴露不是一回事。长期收益不仅取决于选对行业，还取决于选对基金工具。**

## 13. 对抗式审查

### 半导体设备涨9.53%，为什么不立刻买

三日已经转涨约4.63%，机械PE约108倍；价格上涨远快于已确认现金流。追涨需要假设未来订单、毛利和资本回报大幅兑现，安全边际不足。

### 007484今天可能大涨，二季度跑输还重要吗

重要。一天高弹性来自当前持仓风格，季度超额反映工具选择结果。两者可以同时成立：今天上涨，但长期仍需复核或替换。

### 医疗估值合理偏低，为什么不补仓

行业赔率尚可，但你持有的是前十大占75.1%的主动基金，风险来自选股集中而非只有行业估值；今天价格又在上涨。

### 消费和白酒越跌越便宜，为什么不抄底

PE和股息率改善是真实的，但社零、库存、批价和现金回款没有同步确认。低估是必要条件，不是充分条件。

### 红利低波三日跌3.24%，距离4%很近

你没有该持仓和真实首次买点，且长期分位未确认。4%法不能替代首次买入的质量与估值许可。

### 天弘永利占近一半，为什么不直接卖

产品含权益且阶段性跑输需要复核，但仍有大量固定收益资产并承担稳定职责。应先明确资金用途、赎回成本和替代工具，再分批调整，不因一天行情全部切换。

### 为什么不是等待亏损基金回本再卖

成本是历史信息。若从今天起存在更高质量、费率更低且风险更清晰的工具，等待回本会继续占用机会成本；卖出条件应是未来预期回报和产品质量，而不是账面颜色。
