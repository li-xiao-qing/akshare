FIRST PRINCIPLES

价格改变了边际偏好，没有自动改变价值

长期资产回报 = 盈利与自由现金流增长 + 可持续分红或利息 +/- 估值变化 - 费用、资本开支、竞争和永久性损失

今天确认的是资金偏向煤炭、银行和芯片硬件，同时撤出医疗、新能源、软件与港股科技。它没有证明半导体109倍PE得到现金流支持，也没有证明医疗、消费或新能源的长期盈利预测发生永久性下降。

决策原则：不追最强行业，不卖最弱行业；只有投资论点中的现金流、竞争结构或估值门发生变化，才改变动作。

HOLDING QUALITY

行业与基金工具要分开判断

医疗与中欧医疗A

医疗ETF跌1.78%，基金只跌0.74%；前十大按二季报权重贡献约-0.67个百分点。行业估值不高，主动基金阶段性抗跌，但前十大占75.1%，决定了不能无条件补仓。

消费与重复基金

000083跌0.28%，好于消费ETF；食品饮料和白酒小仓与它重复。行业持有等待需求改善，产品层停止重复新增。

光伏与新能源

两只指数产品分别跌1.13%和1.23%。终端需求仍在，制造端自由现金流和供给退出尚未确认；持有、不补。

核心科技A

007484涨0.78%，受中小盘芯片硬件支撑；但二季度落后基准24.31个百分点。现有小仓持有，停止新增，连续超额不修复则替换。

偏债与QDII

两只偏债接近平盘，但天弘永利含约12.8%股票；QDII反映8月5日海外回落。标普作为核心候选，两只纳指以后只保留一个新增渠道。

AI INDUSTRY

需求真实，但今天仍不新增AI仓

AI股东回报 = AI增量收入 × 可持续利润率 - GPU、网络、存储、电力、折旧与融资成本 - 后续资本开支 - 买入估值

微软Azure增长43%和商业剩余履约义务增长84%，说明需求真实；Meta收入增长28%，但单季资本开支310.8亿美元、自由现金流7.84亿美元，说明增长可能先消耗现金。

今天半导体设备、通信和半导体上涨，AI主题、云计算与软件下跌。硬件景气交易仍在，但应用商业化没有同步被价格确认。

优先级环节必须验证
1云平台、企业软件、AI应用付费收入、续费、毛利率、自由现金流
2网络、光通信、存储、电力、冷却订单、应收、客户集中和扩产回报
3国产设备、材料、先进封装客户验证、良率、折旧和估值
4只有AI标签的公司无收入和现金流则不进入长期核心
你的AI参与权已经存在：007484、纳指、标普和偏债基金中的科技股都提供暴露。看好AI不等于必须再买一只AI主题基金。

EXECUTION METHOD

8月6日没有有效4%触发

质量门 → 指标门 → 估值门 → 基本面门 → 组合门 → 记录最后一次实际买入确认净值 P → 下一笔仅在确认净值 <= 0.96P 时执行
  • 所有持仓正式净值跌幅均未达到4%。
  • 当前只有平均成本，没有最后一次实际买入确认净值和剩余预算。
  • 红利低波没有持仓，不存在上一次买点。
  • 个股、黄金和偏债基金不能机械套用行业基金规则。
结论：4%法负责合格资产的执行节奏，不负责把任何下跌自动转化为价值。

ADVERSARIAL REVIEW

对抗式审查

医疗下跌、估值又不高，为什么不补？

合理偏低不是极度低估，持有的还是高集中主动基金；缺少真实4%锚点和新的盈利上调证据。

煤炭上涨5.88%，为什么不追？

今天只确认价格上涨，未确认长期自由现金流同步增加；更高价格反而降低安全边际。

007484上涨，是否说明基金经理已经修复？

不能。一天收益描述风格弹性，季度超额衡量工具结果；至少需要连续季度验证。

红利低波7倍PE、近5%股息率，为什么还不买？

低增长和行业结构令其绝对PE长期较低；应与自身历史和股息可持续性比较，不能与AI横向比数字。

阿里和中芯下跌，为什么不是买点？

阿里只从合理略微变便宜；中芯下跌后PE仍超过100倍，一天回撤没有创造足够安全边际。

亏损行业为什么继续持有？

今天没有新的永久性损失证据。继续持有不等于永远持有；未来退出依据是现金流、供给结构和工具质量，不是等待回本。
