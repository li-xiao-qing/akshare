## 2. 第一性原理框架

基金本身只是底层资产的集合，长期收益最终来自：

```text
长期总回报 ≈ 企业盈利增长
           + 股息和回购收益
           + 估值变化
           - 基金费率、跟踪误差和交易摩擦
```

因此，买卖基金不能只看当天涨跌或持仓盈亏：

- 下跌不等于低估，可能是盈利预期下降。
- PE 低不等于一定便宜，周期行业在盈利高点可能呈现低 PE。
- 分红不是额外收益，基金分红后净值会相应除息。
- 历史分位只能说明相对位置，不能预测短期涨跌。
- 即使资产低估，仓位已经过重时也不应该继续买入。
- 持有一只基金，本质上等于每天重新判断是否愿意按当前价格继续配置它。

## 8. 红利与红利低波

### 8.1 普通中证红利

普通中证红利的 PE 约7.97倍、PB约0.77倍，股息率约4.6%-5.1%。绝对数字看起来不贵，但 PE 处于近十年约61.7%分位，说明相对自身历史并没有进入明显低估区间。

结论：可以作为观察方向，但当前不是比红利低波更优的首选。

### 8.2 红利低波

`512890`跟踪的中证红利低波指数近期 PE 约7.4倍，股息率约4.9%-5.1%；红利低波100指数近期 PE 约8.39倍、PB约0.83倍、股息率约4.71%。

红利低波的投资逻辑不是“靠基金分红白拿收益”，而是：

1. 底层公司产生较稳定现金流。
2. 公司把部分现金流以股息方式返还股东。
3. 低波动筛选减少高波动、高估值或经营不稳定公司的权重。
4. 在估值没有明显透支的前提下，股息和盈利共同构成长期回报。

需要警惕的风险包括银行净息差、资源价格周期、公用事业监管定价、分红削减以及市场利率上升。高股息不等于低风险。

综合判断：红利低波处于合理偏低区间，可以小额建仓，但不属于可以一次性重仓的极端低估。

## 11. 对4%定投口径的修正

此前文档中的0.4809、1.6885、0.6327、0.7623等价格，是以20260707观察净值乘以0.96得到的观察线。它们并不是严格意义上的下一买点，除非把20260707净值明确指定为虚拟首买基准。

严格4%定投法应使用：

```text
下一买点 = 上一次实际买入确认净值 x 0.96
```

持仓成本是多次交易后的平均价格，不能替代最后一次实际买入净值。由于当前持仓文档没有记录最后一次买入日期和确认净值，本文只能将这些价格称为“观察线”，不能称为已触发的真实买点。

这意味着 `012831`虽然已经跌破0.6327观察线，也不能仅凭这一点判定4%法正式触发；同时它还没有通过周期估值和仓位上限检查，因此当前仍不买。
