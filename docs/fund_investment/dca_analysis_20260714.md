## 2. 第一性原理：先分清价格、价值和仓位

股票和权益基金的长期价值最终来自底层企业未来可分配现金流：

```text
内在价值 = Σ（未来自由现金流 ÷ (1 + 要求回报率)^时间）
```

一天上涨只表示市场支付的价格提高。只有未来收入、利润率、资本开支、竞争优势或风险溢价发生可持续变化，内在价值才会同步变化。

因此，每次买入应依次通过四道门：

```text
长期逻辑仍然成立
    ↓
估值处于合理偏低或低估
    ↓
价格达到实际4%买点
    ↓
买入后不突破组合仓位上限
```

20260714的主要矛盾不是“有没有上涨”，而是：低估方向已经持有、医疗过度集中、宽基并不便宜。仓位纪律必须与估值纪律同时生效。

## 9. 与4%定投法的关系

4%法解决的是“已经允许买入以后，下一份什么时候买”，不能代替估值和仓位控制。

| 检查项 | 20260714状态 | 结论 |
| --- | --- | --- |
| 长期逻辑是否有效 | 消费、医疗、红利低波大体有效；新能源仍需观察盈利周期 | 只有逻辑有效的标的进入下一步。 |
| 估值是否低或合理偏低 | 消费、白酒、食品、医疗通过；宽基未通过 | 宽基当日不买。 |
| 是否较上次实际买点下跌4% | 大多数方向当日上涨；仓库没有完整实际成交锚点 | 不触发正式买入。 |
| 买入后仓位是否合理 | 医疗不满足；消费存在重叠 | 即使估值低也不加仓。 |
| 是否进入高估卖出区 | 医疗、消费等未进入 | 不因上涨一天清仓。 |

因此，20260714的执行结果是：

- 4%法没有发出新买入信号。
- 估值法支持继续持有消费、食品、白酒和医疗。
- 仓位控制否决医疗继续加仓，并允许小幅再平衡。
- 红利低波进入首仓观察池，但当天价格上涨，不需要追买。
- 宽基估值未通过，不能因为大盘反弹就建立新仓。
