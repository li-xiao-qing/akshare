FIRST PRINCIPLES

3. 第一性原理：普涨改变了什么

长期资产回报
= 盈利与自由现金流增长
+ 可持续分红或利息
+/- 估值变化
- 费用、资本开支、竞争和永久性损失

基金长期回报来自底层公司的股东回报，减去费用、交易损耗、跟踪误差和基金经理错误。一天普涨主要改变市场支付的估值倍数，不会让所有企业的长期现金流同时增长1%。

8月10日确认的是：市场愿意提高消费、医药、资源和多数中小盘资产的价格，同时降低AI、通信和云计算的价格。它没有自动确认：

  1. 消费收入、库存与回款已经形成持续拐点。
  2. 医疗订单、管线成功率和自由现金流已经全面进入新周期。
  3. 半导体设备3.25%的上涨可以消化广义半导体超过112倍的机械PE。
  4. 光伏和新能源已经完成产能、价格、库存和减值出清。
  5. 红利低波上涨0.35%后仍属于严格历史低估。

因此，正确动作不是追逐今天上涨行业，也不是因为某个持仓连续上涨就机械减仓；应检查长期现金流、竞争结构、估值和工具质量。今天没有足够新证据改变资产层动作。

7. AI产业：回调后是否可以买

AI股东回报
= AI增量收入 × 可持续利润率
- GPU、网络、存储、电力、折旧与融资成本
- 后续资本开支

微软FY2026 Q4收入增长18%、Azure增长43%、商业剩余履约义务增长84%，说明AI和云需求真实。Meta Q2收入增长28%，但单季资本开支310.8亿美元、自由现金流仅7.84亿美元，说明产业扩张也可能先消耗股东现金。

8月10日AI主题、通信、云计算和机器人下跌，半导体设备上涨3.25%。这更像高估科技内部重新选择，而不是AI产业逻辑统一破坏。真正重要的不是“AI今天跌了”，而是未来收入、利润和现金流能否覆盖已经支付的估值。

AI机械PE回落到约56倍，半导体仍约113倍。一天回调没有创造充分安全边际。你的账户已经通过007484、两只纳指、标普500以及偏债基金中的科技股获得参与权。

长期优先级：

  1. 云平台和应用：验证付费收入、续费率、毛利率与自由现金流。

  4. 只有AI标签、没有收入和现金流的公司，不进入长期核心。

DIVIDEND & CORE

8. 红利低波与A股宽基

8.1 红利低波

红利低波长期回报
= 可持续股息率 + 盈利增长 +/- 估值变化
- 分红削减、行业集中、费用和税费

红利低波ETF上涨0.35%，机械PE约7.72倍、股息率约4.92%。绝对收益率具有吸引力，但缺少可靠完整十年分位，不能严格宣布已经进入历史20%低估区。

真正买入前还要检查股息是否由自由现金流覆盖、指数换仓规则、银行和能源集中度，以及场外联接基金是否真正现金分红。

结论：继续观察，不因绝对PE低就立即建仓。 若家庭确实缺少战略分红资产，可另行制定1%-2%小额试仓方案，但那属于资产配置，不是8月10日估值或4%触发。

10. 4%定投法：今天是否触发

质量门 -> 指标门 -> 估值门 -> 基本面门 -> 组合门
-> 记录最后一次实际买入确认净值P
-> 下一笔仅在确认净值 <= 0.96P时执行
  • 今日多数持仓方向上涨，没有出现向下4%的价格触发。
  • AI主题下跌2.79%、007484估算下跌不足2%，均未达到4%；更重要的是007484产品质量门仍未通过。

  • 账户仍缺少每只基金最后一次实际买入确认净值、金额和剩余预算。
  • 平均持仓成本不等于最后一次实际买入净值。
  • 红利低波没有现有仓位，不存在可供4%法使用的上一次买点。

结论：8月10日没有任何可审计的4%买入触发。 估值法决定“值不值得买”，4%法只决定“合格后何时分批买”。

ADVERSARIAL REVIEW

13. 对抗式审查

超过4000只股票上涨，为什么还不买

市场广度说明风险偏好改善，不说明买入价格具有安全边际。今天上涨主要改变估值倍数，没有让所有企业现金流同步提高；追涨会降低未来赔率。

医疗连续上涨，为什么不趁机减仓

减仓需要价格超过合理价值或组合触发预设再平衡。医疗约29.9倍机械PE不属于明显高估，今天也没有基本面恶化。组合集中要求停止新增，但不能直接推出资产应卖。

消费估值偏低，为什么不加仓

低估值提高长期赔率，但上半年需求增速仍弱；今天2%以上上涨又减少了安全边际。已有仓持有，等待收入、库存和回款共同改善更稳健。

AI下跌2.79%，为什么不抄底

AI机械PE仍约56倍、半导体约113倍；一天跌幅不足以消化高增长预期。007484还存在产品质量问题，价格门之前的质量门没有通过。

半导体设备上涨3.25%，为什么不追国产替代

产业逻辑可能成立，但更高价格需要更高未来订单、毛利和自由现金流兑现。半导体整体下跌说明市场并未确认全产业链同步改善。

红利低波接近5%股息率，为什么仍不买

低增长和行业集中令其绝对PE长期较低。应与自身历史、股息覆盖和产品实际分红规则比较，不能只与AI横向比数字。

账户今天上涨，是否说明组合已经合理

不是。医疗仍贡献主要波动，消费和纳指重复、科技工具质量、宽基缺失及交易数据问题都没有因一天上涨消失。
