3.3 第一性原理解释

今日行情不是“牛市重新开始”或“AI结束”二选一，而是四股力量同时作用：

上周五集中抛售后的均值回归
+ 白酒价格调整、央企增持与回购等短期催化
+ 地缘风险抬升能源、电力、煤炭和防守资产相对吸引力

= 大盘价值、消费、医疗和AI应用上涨，硬件与新能源继续承压

白酒、煤炭和电力的上涨有明确事件催化；医疗上涨更适合解释为低估值和超跌后的风险溢价回落。一天行情不能证明白酒终端动销、医疗企业利润或AI应用自由现金流已经形成持续拐点。

4.2 红利低波能否买

红利低波的价值来自：

预期总回报
= 可持续股息率
+ 企业盈利增长
+ 估值变化
- 基金费用和税费

按7月17日约4.98%股息率、今天价格上涨2.27%机械调整，当前股息率约4.87%。这个现金收益率有吸引力，但PE约处近十年69%分位，严格估值法不能称为低估。

因此：

  • 作为长期分散工具，它比新增医疗、消费或AI主题更符合当前组合需要。
  • 作为“低估买入”对象，今天不满足条件，且连续上涨后不应追价。
  • 未来若配置场外产品，应继续比较007467、016128/016129的跟踪指数、总费率、持有期和实际分红；分红本身会除息，不是额外收益。
  • 如果以后决定建立战略仓，先确定目标权重，再由首笔实际确认净值建立4%锚点。

HOLDINGS

每类持仓的买卖判断

5.1 医疗：便宜和集中可以同时成立

医疗的内在价值来自患者需求、支付能力、产品成功率和可实现自由现金流，而不是来自“跌了很多”：

医疗内在价值
= 已上市产品可持续现金流
+ 在研管线成功后的概率加权现金流
- 研发失败、集采降价、医保支付和商业化成本

中证医疗近似PE分位约21%，说明估值压力已经显著释放。但003095是主动基金，创新药、CXO及港股医药暴露可能使它与中证医疗偏离；同时医疗仍占总组合约23.56%。

  • 25%只适合作为防止风险继续扩大的硬上限，不应再被视为长期目标；低于硬上限不等于组合已经合理。
  • 长期第一阶段目标为18%：按当前静态市值约需减少10,600元，计划在未来2-6周分3次执行，不把“等到回本”或“必须再大涨”作为前提。
  • 估值修复到历史中位附近、权重因上涨再次超过18%，或更合适的核心资产通过买入门时，再降到12%-15%。
  • 今天上涨不能成为追加理由，也不应成为一次性清仓理由；减仓依据是集中度，不是对明日涨跌的预测。

5.2 消费、食品和白酒：估值通过，组合门限制买入

白酒和消费仍在历史低估区，但今天主要催化来自茅台价格调整和低位轮动。真正需要验证的是终端动销、渠道库存、批价、合同负债、经营现金流和资本回报。

你已经同时持有主动消费、食品饮料指数和白酒指数。三只产品合计约占组合8.14%，但这不是三种独立风险。当天不追涨；长期默认保留覆盖较广、已形成主要仓位的000083，在赎回费为0或足够低时退出001631/012414。这属于产品去重，不是看空消费，也不需要等待两个小仓回本。

5.3 新能源和光伏：价格变低，盈利质量仍未知

新能源PE分位约30%，比宽基和AI便宜；光伏仍约55%分位。对周期行业，低PE可能来自尚未下修的利润，高PE也可能来自周期底部利润，因此必须观察产能出清、价格、库存、毛利率、现金流和资本开支。

现有两只合计约7.58%，明显高于长期只保留一个新能源卫星仓的结构目标。012831覆盖更广，当前约占组合3%，可作为唯一新能源小仓继续持有但停止补仓；011102是更窄的纯光伏暴露，下一次费率合适时先退出约一半，后续若供需和自由现金流没有共同改善则退出剩余份额。

5.4 固收增强和QDII

  • 420102和012951合计约占56.08%，提供主要缓冲，但都不是无风险现金。应继续检查股票仓位、久期、信用风险和回撤。

AI INDUSTRY

AI产业：应用反弹，硬件仍在去估值

6.1 产业没有一天内崩溃

台积电2026Q2业绩和SEMI设备支出预测仍支持先进制程、存储及设备需求扩张。产业需求强，只能说明质量门可能通过，不能证明证券价格便宜：

AI股东回报
= AI收入和成本节约
- 芯片、云、数据中心、模型与获客成本
- 持续研发和资本开支
- 估值回归损失

6.2 今天的分化

  • AI综合和云计算上涨约2.3%-3.5%，说明资金开始关注应用、平台和商业化收入。
  • 半导体、设备和通信下跌约2.1%-5.7%，说明资本开支受益链仍在消化高估值和拥挤交易。
  • 港股阿里、腾讯及数据中心相关方向盘中修复，也符合从“投入多少”转向“收入和现金流能否兑现”的逻辑。
  • 一天轮动不能确认新主线；人工智能主题约86%分位，半导体约97%分位，估值门仍失败。

6.3 对现有持仓的含义

007484约占组合2.65%，加上纳指和标普QDII，组合已经有平台、应用及海外AI暴露。当前不存在必须补齐AI仓位的目标，继续小仓持有、不补仓即可。

4% DCA

4%定投法：今天没有正式触发

正确公式仍是：

下一买点 = 上一次实际买入确认净值 × 96%

当前持仓表记录了平均成本和观察日净值，没有记录每只基金最后一次实际买入确认净值。平均成本不是4%锚点，单日涨跌也不是4%触发。

因此，即使上周五003095和007484单日下跌超过4%，也不构成4%法买点。价格门不能绕过组合门和估值门。

RISK GAPS

当前最大的遗漏

  1. 医疗仍占风险资产一半以上。 今天盈利约80%来自医疗，与上周五亏损主要来自医疗是同一个问题，不是风险已经消失。
  2. 缺少最后一次实际买入记录。 没有确认净值、金额和剩余预算，4%法无法严谨执行。
  3. 没有完整家庭资产视图。 持仓表不含现金、实物黄金、房产、负债和未来用款，黄金及权益目标仓位只能给条件结论。
  4. 缺少A股核心宽基。 这是结构性空缺，但沪深300当前约70%PE分位，不应为了补齐结构而追买。
  5. 固收增强不是现金。 组合看似防守，但两只产品仍可能同时承受权益、利率和信用风险。
  6. 基金净值估算和季报持仓均有误差。 今天的动作应以风险规则为核心，最终净值只用于事后校正金额。

ADVERSARIAL REVIEW

对抗式审查

质疑一：医疗和白酒都低估，为什么不马上买

医疗被组合门拦截，白酒被重复持仓和今日追涨风险拦截。低估是必要条件，不是充分条件。

质疑二：红利低波PE只有7倍多，为什么不算低估

绝对PE低是因为其行业结构、盈利增速和风险特征长期不同。相对自身近十年，当前约69%分位；约4.87%股息率有吸引力，但不是免费收益，企业盈利和分红下降仍会造成损失。

质疑三：AI已经连续大跌，今天应用又反弹，是否应该抢先布局

可能继续反弹，但人工智能和半导体估值仍约处86%和97%分位。错过短期反弹是机会成本，在高分位耗尽风险预算则可能造成更大损失。组合已有小额AI参与权。

质疑四：今天组合赚钱，是否说明持仓已经合理

不能。约80%的境内盈利来自医疗，医疗又占风险资产约54%。收益集中和风险集中是同一件事的正反两面。

质疑五：沪深300不是最贵，为什么不先补宽基

建立核心宽基方向正确，但当前约70%PE分位不符合严格低估买点。应先确定核心目标权重和资金计划，再等待更合理估值，不能因结构缺口牺牲买入纪律。

质疑六：亏损的基金现在卖，不就是割肉吗

亏损只说明历史买入价格高于当前价格，不说明继续持有的预期回报一定更高。重复的小仓位和论点较弱的光伏应按未来收益风险比处理；等待回本会让历史成本替代当前决策。

质疑七：消费和白酒低估，为什么还要卖001631/012414

这里卖的是重复产品，不是完全退出消费。默认仍保留约13,314元的000083，消费风险暴露仍在；清理两个小仓只是减少重复费率、决策节点和无效分散。

质疑八：卖出后现金闲置，会不会错过行情

会有机会成本，但当前沪深300和红利低波都没有通过严格低估门。短期现金闲置的成本，通常低于为了完成换仓而立即买入不便宜资产所承担的估值风险。
