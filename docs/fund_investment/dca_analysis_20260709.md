## 4. 红利低波场外基金筛选

`512890` 是华泰柏瑞中证红利低波动 ETF，属于场内 ETF。如果无法买场内 ETF，可以选择场外联接基金或同类红利低波指数联接基金。

注意：红利低波不是“只靠基金分红赚钱”。基金分红会除息，分红当天净值会相应下降。总收益仍然是：

```text
总收益 = 净值涨跌 + 已分红现金
```

如果目标是现金流，需要在交易平台选择“现金分红”，不要选择“红利再投资”。
