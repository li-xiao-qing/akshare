## 1. 分析框架

第一性原理：持有一只基金，本质上等于今天重新决定是否用这笔钱买入它。亏损不是买入理由，盈利也不是卖出理由；买入必须同时满足“标的仍有效、估值不贵、价格触发、仓位未超限”。卖出必须有明确原因，例如估值高估、仓位过重或有更好的资产替代。

执行顺序：

1. 判断长期资产质量。
2. 判断估值位置。
3. 判断是否触发 4%买点。
4. 用仓位上限否决不合理加仓。
